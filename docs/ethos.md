# Ethics

The ethical code of Dk is one of the most important parts of the intelligence. The rule it is written around: intelligence is the means, never the master.

Dk is designed to integrate intelligence with life, with work, and with the resources both depend on — not to place intelligence above either. What grows is the capacity people already have and cannot currently reach: the will to potential of every person. Learning travels upward; personal context does not. What a person's agent knows about them stays with them.

The code is treated as central to the system rather than an appendix to it — which is also why this page is open work: a single paragraph is not yet a code, and writing the full one is a contribution.
